# CH06 art briefs — `24 ÷ 6`

Use exact vector diagrams for arrays, bars, number lines, equations, arrows, and labels. Raster/composite scenes may supply tactile counters or hands, but must not contain generated text.

## Required checks

1. There are exactly 24 objects.
2. Sharing scenes have exactly 6 groups with 4 objects each.
3. Grouping scenes have exactly 4 groups of 6.
4. Number-line scenes have four equal jumps of 6 from 0 to 24.
5. Finger scenes show four raised fingers and never imply a fixed learner identity.

## Prompt set

- `ch06_m01_equal_share_counters.svg`: 24 counters dealt into six bowls, four per bowl.
- `ch06_m02_groups_of_six.svg`: 24 counters bracketed into four groups of six.
- `ch06_m06_four_by_six_array.svg`: exact 4×6 dot array with row/column braces.
- `ch06_m09_finger_group_counter.png`: anatomically credible hand with four raised fingers beside a precise four-jump number line.
