# Task packet conventions

Use `CHAPTER_TEMPLATE.md` for any chapter. Replace `{NN}`, `{slug}`, and the owned manuscript path with the values in `book/CHAPTERS.json`. Research, design, web, and QA lanes have dedicated packets.

Use `CHAPTER_IMAGE_PASS.md` for the serial, full-coverage picture audit/markup/revision pass. Chapter selection and completion state live under `coordination/chapter-image-passes/`; do not substitute the historical `qa/reports/image_review_chNN.md` files for the required detailed audit.
